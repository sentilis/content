# Bio Advanced Guide 🚀

To write your resume, we suggest using the **Harvard Style**: clean text, no weird columns, and bullet points starting with action verbs (e.g., *Led*, *Developed*).

To be the AI's best friend (AI-Friendly), we **recommend** using standard headings like `## Experience`, `## Education` or `## Skills`. *(Don't worry if you decide to use "## Work Experience", modern AI will understand it, but using standards helps avoid any confusion).*

**Image Support:** Besides text, your Bio content supports embedded images (`![alt](path)`) in common web formats (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`). If you use the directory structure, simply save your images in the `attachments/` folder and reference them in your text.
